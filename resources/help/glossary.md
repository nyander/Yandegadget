| Word                  | Means                                                                                           |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| **Product**           | What something is, e.g. "iPhone 13 128GB". Customers see products on the website.               |
| **Stock unit / item** | One physical thing you own, with its own condition, cost and price. Reference like `YG-000123`. |
| **Condition / grade** | How good an item is (A, B, C…). Each grade has a request deposit.                               |
| **Cost**              | What you paid for an item, in pounds. Never shown to customers.                                 |
| **List price**        | What you want for an item, in pounds. Shown to customers in cedis.                              |
| **Exchange rate**     | How many cedis one pound is worth. You set it.                                                  |
| **Lowest price**      | The least staff can sell for: a percentage of the listed cedi price.                            |
| **Shipment**          | A set of items sent from the UK to Accra. Reference like `SH-0001`.                             |
| **Dispatch**          | Marking a shipment as sent.                                                                     |
| **Check in**          | Staff ticking off each item when a shipment arrives.                                            |
| **Request**           | A customer asking you to find something. Reference like `RQ-00001`.                             |
| **Deposit**           | What a customer pays online to start a request. It comes off the price.                         |
| **Reserved**          | Held in the store for the customer who requested it.                                            |
| **Cancellation fee**  | The part of a deposit you keep if a customer cancels after you've found their item.             |
| **Void**              | Cancelling a sale that was recorded by mistake. The item goes back on sale.                     |
| **Ledger**            | Where you record money the app can't work out itself: rent, bills, loans, cash.                 |
| **Gross profit**      | Sales minus what the sold items cost you.                                                       |
| **Net profit**        | Gross profit minus shipping, wages and other expenses.                                          |
| **Write off**         | Removing an item that's lost or broken from your stock.                                         |
